# infra-notes

인프라 운영 및 자동화 과정에서 정리한 개인 노트 저장소입니다.

실무에서 직접 겪은 설정, 트러블슈팅, 운영 절차를 기록하여  
재사용 가능하고 다시 봐도 이해할 수 있는 형태로 정리하는 것을 목표로 합니다.

## 목적

- 인프라 운영 중 반복되는 작업 및 설정 정리
- 서버 / 네트워크 / 컨테이너 / Kubernetes 관련 노트 축적
- 장애 대응 및 운영 자동화를 위한 참고 자료 저장
- 개인 학습 기록 및 실무 지식 아카이빙

## 구성 예시

- Linux 기본 명령어 및 운영 노트
- 서버 설정 및 트러블슈팅 기록
- Docker / Container 운영 정리
- Kubernetes / Ansible 관련 문서
- 스크립트 및 설정 파일 예시

## 참고 사항

- 본 저장소는 개인 학습 및 운영 노트 목적입니다.
- 환경에 따라 일부 내용은 그대로 적용되지 않을 수 있습니다.
